## Summary
Copperlane is an AI mortgage origination platform: an assistant ("Penny") that
automates document collection and application completion between loan
officers and borrowers, cutting down manual back-and-forth. Saved as a design
reference — the landing page treats an AI product with clean, confident,
professional polish rather than generic "chat widget" styling.

## Key points
- AI assistant does document collection, auto-populates forms, adapts fields
  to loan type, and flags issues before underwriting.
- Unified dashboard gives loan officers one view across applications and
  documents; multilingual support for borrowers (13 languages).
- Landing page: clean modern layout, clear sectional breaks, strong
  typographic hierarchy, product mockups doing the explaining instead of
  copy-heavy blocks, corporate-credible but approachable color palette.

## How it applies here
Relevant as inspiration for Valgate's own AI-assisted flows (Khmer scan,
in-app AI, MCP tools) — specifically how to present an AI agent doing
real backend work (documents, forms, verification) through a trustworthy,
uncluttered UI rather than a chatty assistant gimmick. Worth revisiting when
polishing the AI-overlay or scan-accuracy surfaces (see
`docs/ai-overlay/`, [[khmer-scan-self-consistency]]).
